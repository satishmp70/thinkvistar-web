# 30 / 60 / 90 day roadmap

## Days 0–30 — launch and foundations
Deploy via `deploy` branch; rotate secrets; verify Search Console + Bing; submit sitemap; IndexNow ping (`node src/indexnow.mjs`); set up GA4/Plausible with events (form submit, WhatsApp click, estimator completion, phone/email click); Google Business Profile + LinkedIn + 3 directories; ask 3 clients for links/testimonials; run AI evaluation baseline; check live Core Web Vitals report once data accrues.
**Success:** pages indexed, brand query returns the site, analytics firing.

## Days 31–60 — trust and content
Publish 3–4 articles (cost guide, MVP guide, CMS migration, contract checklist); first real case study; team/founder page + `Person` schema; Rich Results Test; fix Search Console coverage issues; first 5–10 genuine directory/community mentions.
**Success:** impressions growing for long-tail queries; first non-brand clicks.

## Days 61–90 — authority and iteration
Publish 3–4 more articles and 2nd case study; review reviews/testimonials; refine titles/descriptions of pages with impressions but low CTR; expand pages that rank 8–20; competitor backlink-gap outreach; repeat AI evaluation and compare with baseline.
**Success:** measurable non-brand impressions, qualified organic leads, AI answers describing Thinkvistar accurately.

## Metrics to track (monthly, from Search Console/GA/CrUX; none exist yet)
Impressions, clicks, non-brand queries, average position by page (interpret carefully), indexed canonical pages, qualified leads and conversion rate, CWV (LCP/INP/CLS at p75), referring domains, AI citations/accuracy. No traffic or ranking target is promised; new domains typically need months.
