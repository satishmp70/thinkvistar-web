FAQ

Frequently asked questions

What does a software maintenance plan include?

Monitoring and alerting, security patching, dependency updates, backups, bug fixes within agreed response times, and a set number of hours each month for improvements.

Can you support software built by another company?

Yes. We start with a health check of the code and infrastructure, document the risks we find, and fix the urgent ones before regular support begins.

What response times do you offer?

Response times are agreed in your support plan based on how critical the system is — faster for production outages, slower for minor requests.

Is support included after a new project launches?

Every project includes a 30-day warranty after completion for defects against the agreed acceptance criteria. After that you can move to a monthly support plan.
